进阶说明

普通用户请走首页三步：粘贴链接 / 开始 / 打开阅读页。本产品只接受链接，不提供本地音视频上传。下面给脚本与自建环境。

1. 健康检查

curl -s http://127.0.0.1:8200/livez
curl -s http://127.0.0.1:8200/health

/livez 只表示进程活着。/health 会查 SQLite、磁盘、可选 ASR；CapsWriter / FunASR / LLM 未配置时出现 degraded 是预期降级，不代表首页不可用。

2. 提交任务（API）

curl -s -X POST http://127.0.0.1:8200/transcribe \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_KEY" \
  -d '{"url":"https://example.com/video"}'

Key 写在 config/users.json；切勿把真实密钥放进仓库。

3. 环境与配置

  • 主配置：config/config.jsonc（可参考 config/config.example.jsonc）
  • 部署环境变量样例：docker/ops.env.example、.env.example
  • 产品显示名：环境变量 VTA_APP_NAME 或 APP_NAME（默认「阅稿」）
  • OpenAPI：/docs

4. 两条路径怎么选

  • 普通用户：首页 → 开始 → 阅读页 / 历史
  • 进阶用户：本页 + /docs + 配置文件；不依赖聊天 Agent

5. ASR 降级（CapsWriter 可选）

没有 CapsWriter 也能用。推荐顺序：

  1. Path A：Amy（或其它工具）先出 Markdown/纯文本 → 导入 VTA → 打开 /view/{token}。
  2. local_whisper：在 config.jsonc 启用 local_whisper，并用环境变量指定带 Whisper 的解释器： 
    LOCAL_WHISPER_PYTHON=/path/to/python
AMY_PYTHON=/path/to/venv/bin/python
    解析顺序：配置里的 local_whisper.python → LOCAL_WHISPER_PYTHON → AMY_PYTHON → 本机候选。
  3. Path B（可选）：自建 CapsWriter / FunASR 后再走完整 URL 转写。

详情见仓库 docs/guides/asr-degrade.md 与 SECURITY.md。

6. 已知限制（摘要）

  • /view 链接拿到即可读；局域网勿裸暴露公网。
  • 章节时间戳为 segment 反查的近似值。
  • 飞书 / TikHub 未配置则跳过；公开 CI 不做分钟级 E2E。
